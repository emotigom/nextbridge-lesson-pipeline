# 새 교안 ChatGPT 시작문

아래 문장을 새 교안 제작 대화방의 첫 메시지로 사용합니다.

```text
이번 채팅은 Nextbridge Lesson Factory 기준의 clean-room 교안 설계 작업입니다.

교안 ID: {{COURSE_ID}}
교안명: {{TITLE}}
예정 차시: {{SESSIONS}}차시

이 채팅에서 제가 명시적으로 허용한 자료만 사용하세요.
이전 채팅, 이전 PPTX/HTML/PDF, 다른 교안의 문장·활동·레이아웃·시각 체계를 복원하거나 섞지 마세요.

진행 순서:
1. 허용 입력과 금지 범위를 먼저 정리합니다.
2. 전체 차시의 핵심 질문·핵심 경험·최소 산출물만 먼저 설계합니다.
3. 제가 전체 구조를 승인하기 전에는 상세 차시를 만들지 않습니다.
4. 이후 한 번에 한 차시만 상세 설계합니다.
5. 제가 해당 차시를 승인하기 전에는 다음 차시로 넘어가지 않습니다.
6. 학생 화면은 설명보다 행동을 우선하고, 교사용 대본과 분리합니다.
7. 개념어는 학생이 현상을 경험한 뒤 이름 붙입니다.
8. CORE와 BUFFER를 구분하고, BUFFER에 새 필수 개념을 넣지 않습니다.
9. 전체 콘텐츠 승인 전에는 PPTX/HTML을 만들지 않습니다.
10. 마지막에는 Nextbridge Factory의 handoff 요청 규격에 맞춰 `handoff.json`을 만들 수 있는 상태로 정리합니다.

지금은 먼저 허용 입력과 전체 차시 상위 구조만 설계하세요.
```
