# 새 교안 ChatGPT 시작문

아래 문장을 새 교안 제작 대화방의 첫 메시지로 사용합니다.

```text
이번 채팅은 Nextbridge Lesson Factory 기준의 clean-room 교안 설계 작업입니다.

교안 ID: {{COURSE_ID}}
교안명: {{TITLE}}
예정 차시: {{SESSIONS}}차시

이 채팅에서 제가 명시적으로 허용한 자료만 사용하세요.
이전 채팅, 이전 PPTX/HTML/PDF, 다른 교안의 문장·활동·레이아웃·시각 체계를 복원하거나 섞지 마세요.

교안 내용을 만들기 전에 수업 레퍼토리를 먼저 확정합니다.
`경험 먼저`를 보편적인 기본값처럼 가정하지 마세요.

Factory deliveryProfile 후보:
- `experience-first`: 경험 → 비교/발견 → 학생의 말 → 개념에 이름 붙이기 → 다시 적용
- `guided-build`: 주제/맥락 → 필요한 이론 → 짧은 영상 또는 완성 예시 → 오늘 만들 것 설명 → 강사와 함께 실습 → 학생이 자기 것으로 바꾸기 → 결과 확인
- `explain-practice`: 설명/시연 → 연습 → 확인

도구를 사용하는 제작형 수업이라면 Course Map 전에 다음을 함께 승인받으세요.
- `practiceAnchor.tool`: 학생과 강사가 실제로 사용할 핵심 도구
- `practiceAnchor.studentBuild`: 학생이 수업 중 실제로 완성할 결과물 한 문장

`guided-build`에서는 설명 약 15분 → 실습 약 20분 같은 덩어리를 주제와 차시에 맞게 반복할 수 있습니다. 이 시간은 고정 규칙이 아니라 현장 가이드입니다.
필요한 이론은 실습 전에 짧게 설명할 수 있으며, 모든 개념을 무조건 경험 뒤로 미루지 않습니다.
영상/완성 예시는 곧 이어질 실습의 목표 모습을 보여주는 데 사용합니다.
실습은 강사가 학생과 같은 화면을 보며 함께 진행할 수 있어야 하고, 이후 학생이 숫자·조건·프롬프트·디자인·오브젝트 등 최소 한 가지를 자기 것으로 바꾸게 합니다.

진행 순서:
1. 허용 입력과 금지 범위를 먼저 정리합니다.
2. `deliveryProfile`과, 제작형 수업이면 `practiceAnchor`를 먼저 제안합니다.
3. 제가 deliveryProfile/practiceAnchor를 승인하기 전에는 전체 차시 상세 구조를 만들지 않습니다.
4. 승인 후 전체 차시의 핵심 질문·핵심 실습·최소 산출물만 설계합니다.
5. 제가 전체 구조를 승인하기 전에는 상세 차시를 만들지 않습니다.
6. 이후 한 번에 한 차시만 상세 설계합니다.
7. 제가 해당 차시를 승인하기 전에는 다음 차시로 넘어가지 않습니다.
8. 학생 화면과 교사용 대본을 분리합니다.
9. CORE와 BUFFER를 구분하고, BUFFER에 새 필수 개념을 넣지 않습니다.
10. 전체 콘텐츠 승인 전에는 PPTX/HTML을 만들지 않습니다.
11. 마지막에는 Nextbridge Factory의 handoff 요청 규격에 맞춰 `handoff.json`을 만들 수 있는 상태로 정리합니다.

지금은 허용 입력과 deliveryProfile/practiceAnchor까지만 정리하세요.
```
